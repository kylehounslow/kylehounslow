I'm a Senior Software Engineer at AWS on OpenSearch Observability, based in Vancouver, BC. I work on open source telemetry for AI agents: getting traces, logs, and metrics from agent frameworks into OpenTelemetry and making them queryable in OpenSearch.

[LinkedIn](https://www.linkedin.com/in/kylehounslow/) · [Talks](https://sessionize.com/kyle-hounslow/)

#### What I work on

- **OpenTelemetry Collector:** author and code owner of [`genainormalizerprocessor`](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/main/processor/genainormalizerprocessor), which maps OpenInference, OpenLLMetry, and custom GenAI attributes to the OTel GenAI semantic conventions. Ships in `otelcol-contrib`. Also a code owner of [`opensearchexporter`](https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/main/exporter/opensearchexporter).
- **OpenSearch:** maintainer of [observability-stack](https://github.com/opensearch-project/observability-stack) (a local OTel + OpenSearch stack for agent observability) and [genai-observability-sdk-py](https://github.com/opensearch-project/genai-observability-sdk-py). Contributor to [agent-health](https://github.com/opensearch-project/agent-health), [data-prepper](https://github.com/opensearch-project/data-prepper), and [sql](https://github.com/opensearch-project/sql).
